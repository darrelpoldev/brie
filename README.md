# [BRIE](https://darrelpoldev.github.io/brie/) 🎈

A free, Montessori-inspired toddler play app for ages 2–4.

**Play, explore & discover** — no ads, no rules, no data collected. Just play!

## Toys

- **Shape Play** — Tap to drop 3D shapes, then drag them around
- **Patterns** — Complete shape patterns by picking the right piece

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech

- Vite + React 18
- Web Audio API for sound feedback
- Three.js renders the playroom and toy art. React Three Fiber runs the live Royal Poop Battle scene.
- Static progressive web app. Game state stays local and there is no backend.
- Mobile-first, touch-friendly
